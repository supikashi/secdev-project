# SBOM & SCA Evidence

This directory contains Software Bill of Materials (SBOM) and Software Composition Analysis (SCA) artifacts generated by the CI pipeline.

## Files

- **`sbom.json`** - CycloneDX format SBOM generated by Syft, listing all dependencies and components
- **`sca_report.json`** - Full vulnerability scan report from Grype analyzing the SBOM
- **`sca_summary.md`** - Human-readable summary with severity distribution and key findings

## Generation

These files are automatically generated by `.github/workflows/ci-sbom-sca.yml` on:
- Push to `main` or `p09-*` branches
- Manual workflow dispatch

## Usage

1. **For Security Reviews**: Check `sca_summary.md` for quick overview of vulnerabilities
2. **For Detailed Analysis**: Review `sca_report.json` for complete vulnerability details
3. **For Compliance**: Use `sbom.json` for dependency tracking and supply chain security
4. **For DS Section**: Reference these artifacts in final project documentation

## Traceability

Each artifact is linked to:
- Specific commit SHA
- GitHub Actions workflow run
- Date/time of generation

See workflow logs in Actions tab for full traceability.
