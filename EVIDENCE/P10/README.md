# P10: SAST & Secrets Scanning Evidence

This directory contains artifacts from automated Static Application Security Testing (SAST) and secrets scanning.

## Files

- **`semgrep.sarif`** — Semgrep SAST report in SARIF format
  - Contains findings from `p/ci` profile + custom rules
  - Severity levels: ERROR, WARNING, INFO

- **`gitleaks.json`** — Gitleaks secrets scan report
  - Contains potential secrets/credentials in git history
  - Includes file paths, line numbers, and matched patterns

- **`sast_summary.md`** — High-level summary of findings
  - Aggregated severity counts
  - Key actions required

## Generation

Files are automatically generated by `.github/workflows/ci-sast-secrets.yml`:
- Triggered on push to `main`/`p10-*` branches
- Available as GitHub Actions artifacts (90 days retention)
- Not committed to repository

## Usage

These artifacts are intended for:
1. **Security reviews** — identify potential vulnerabilities before merge
2. **Compliance tracking** — demonstrate security scanning in DS section
3. **Continuous improvement** — track security posture over time

## Traceability

Each artifact includes:
- Commit SHA that triggered the scan
- Scan timestamp
- Tool versions (Semgrep 1.95.0, Gitleaks 8.21.2)
- Link to workflow run in GitHub Actions
