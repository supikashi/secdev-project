# P11: DAST - ZAP Baseline Scan

This directory contains artifacts from OWASP ZAP baseline security scanning.

## Files

- **`zap_baseline.html`** — Human-readable HTML report
  - Contains detailed findings with descriptions and recommendations
  - View in browser for full interactive experience

- **`zap_baseline.json`** — Machine-readable JSON report
  - Structured data for automated processing
  - Can be integrated with security dashboards

## Generation

Files are automatically generated by `.github/workflows/ci-dast-zap.yml`:
- Application started on localhost:8080
- ZAP baseline scan runs against running service
- Reports generated and uploaded as artifacts (90 days retention)
- Not committed to repository

## Usage

These artifacts are intended for:
1. **Security validation** — identify runtime vulnerabilities (XSS, SQLi, etc.)
2. **Compliance** — demonstrate DAST scanning in CI/CD pipeline
3. **DS Section** — evidence of dynamic security testing

## Scan Details

- **Tool:** OWASP ZAP (Zed Attack Proxy) stable
- **Scan Type:** Baseline (passive + spider)
- **Target:** http://localhost:8080
- **Trigger:** Push to main/p11-* branches, manual dispatch
